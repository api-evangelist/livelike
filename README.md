LiveLike is an AI-powered fan engagement platform used by sports teams, leagues, media companies, and venues to drive registration, retention, and monetization through interactive experiences. Its developer platform exposes a REST API, GraphQL, webhooks, and native SDKs (iOS, Android, Web, React Native) for building live interactive widgets (polls, quizzes, predictions, alerts), real-time chat and community features, gamification (leaderboards, badges, quests, streaks, rewards), user profiles, and analytics that can be synchronized to live and on-demand video. LiveLike also publishes an official Model Context Protocol (MCP) server so AI assistants can manage programs and widgets.

**Areas:** Company · Fan Engagement · Live Streaming · Interactive Video · Chat · Gamification · Widgets · Sports · Media

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for LiveLike: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
